## Abstract

This paper investigates a deterministic method for representing points in a bounded two-dimensional region using a single real-valued parameter.

The proposed construction uses the irrational Lissajous system

\[
F(t)=(\cos t,\sin(\sqrt{2}t)).
\]

Although the input parameter belongs to the one-dimensional real line, the resulting trajectory is dense in the square \([-1,1]^2\). Consequently, every point in that square can be approximated to arbitrary positive coordinate precision by selecting an appropriate value of the parameter.

We formulate this property as a target-approximation problem and present two complementary methods for finding suitable parameter values. One method fixes the first coordinate exactly and searches for the second; the other fixes the second coordinate and searches for the first.

The construction provides a mathematical example of a one-parameter representation capable of approximating arbitrary points in a two-dimensional region. Its potential implications for geometric encoding, information representation, and reversible computation are discussed. Limitations concerning uniqueness, numerical precision, and information compression are also identified.

## 1. Introduction

Representing multidimensional information using fewer parameters is an important problem in mathematics, computation, and information theory.

This paper examines a particular construction in which a single real-valued parameter generates a trajectory that approaches every point in a two-dimensional square.

The construction is based on two harmonic oscillations with an irrational frequency ratio:

\[
x(t)=\cos(t)
\]

\[
y(t)=\sin(\sqrt{2}t).
\]

The resulting trajectory is unusual because it never settles into a closed periodic pattern.

Instead, it continues to explore the available region without repeating its complete underlying phase state.

The central question is:

**Can an arbitrary two-dimensional target point be represented, to a specified accuracy, by a single parameter value?**

We demonstrate that the answer is yes.

## 2. Mathematical construction

Define the mapping

\[
F:\mathbb R\rightarrow[-1,1]^2
\]

by

\[
F(t)=(\cos t,\sin(\sqrt{2}t)).
\]

The two coordinates are bounded independently:

\[
-1\leq\cos t\leq1
\]

and

\[
-1\leq\sin(\sqrt{2}t)\leq1.
\]

Thus, every point generated by the mapping lies inside the unit square.

To examine the underlying dynamics, introduce angular coordinates:

\[
\theta=t\pmod{2\pi}
\]

\[
\phi=\sqrt{2}t\pmod{2\pi}.
\]

These coordinates describe a linear flow on the two-dimensional torus:

\[
T^2=S^1\times S^1.
\]

The Cartesian representation is obtained by projecting this flow:

\[
P(\theta,\phi)=(\cos\theta,\sin\phi).
\]

This distinction allows us to study the dynamics on the torus while observing the resulting trajectory in ordinary Cartesian coordinates.

## 3. Density theorem

The essential property of the construction is that the frequency ratio is irrational.

Since

\[
\frac{\sqrt{2}}{1}=\sqrt{2}\notin\mathbb Q,
\]

the two angular frequencies are rationally independent.

By the classical Kronecker density theorem, the corresponding linear flow is dense on the two-dimensional torus.

The projection of the torus onto the Cartesian square covers every point in that square.

Therefore,

\[
\boxed{
\overline{F(\mathbb R)}=[-1,1]^2
}
\]

where the overline denotes topological closure.

This establishes the following proposition.

**Proposition 1.**

For every target point

\[
(x_0,y_0)\in[-1,1]^2
\]

and every positive real number \(\epsilon\), there exists a finite parameter \(t\) such that

\[
|\cos(t)-x_0|<\epsilon
\]

and

\[
|\sin(\sqrt{2}t)-y_0|<\epsilon.
\]

### Proof

The irrationality of the frequency ratio guarantees that the trajectory is dense on the torus.

The projection onto the Cartesian square is continuous and surjective.

Consequently, every neighborhood of every point in the square contains points belonging to the projected trajectory.

Therefore, for every positive tolerance, a suitable finite parameter value exists.

This completes the proof.

## 4. Target approximation algorithm

The density theorem establishes existence. We now describe a practical procedure for finding an appropriate parameter value.

Given a target point \((x_0,y_0)\), choose

\[
a=\arccos(x_0).
\]

Consider the sequence

\[
t_n=a+2\pi n,\qquad n=0,1,2,\ldots
\]

The first coordinate is then fixed:

\[
\cos(t_n)=x_0.
\]

The remaining task is to find an integer \(n\) satisfying

\[
|\sin(\sqrt{2}(a+2\pi n))-y_0|<\epsilon.
\]

Because \(\sqrt{2}\) is irrational, the resulting sequence of angular phases is dense modulo \(2\pi\).

Thus, the search eventually succeeds.

An alternative procedure fixes the second coordinate.

Let

\[
b=\arcsin(y_0).
\]

Two families of candidate parameters are

\[
t_n=\frac{b+2\pi n}{\sqrt{2}}
\]

and

\[
t_n=\frac{\pi-b+2\pi n}{\sqrt{2}}.
\]

In this case, the second coordinate is fixed and the first is searched.

Both methods provide a systematic means of approximating the target.

## 6. Dimensional representation

The construction raises an interesting question about the relationship between the dimensionality of a parameter space and the dimensionality of the region it represents.

The input to the mapping is one-dimensional:

\[
t\in\mathbb R.
\]

The output consists of two coordinates:

\[
F(t)\in\mathbb R^2.
\]

Although the trajectory is generated by one parameter, its image is dense in a two-dimensional region.

This demonstrates that a one-dimensional parameterized trajectory can approximate arbitrary locations in a higher-dimensional region.

An important distinction must be made between dense representation and exact one-to-one correspondence.

The construction does not establish a continuous bijection between the real line and the square. Rather, it provides an approximate targeting mechanism with arbitrarily selectable precision.

This distinction is essential to understanding the mathematical significance of the construction.

## 7. Potential applications

### 7.1 Geometric encoding

A two-dimensional target can be associated with a parameter value that reconstructs its coordinates within a selected tolerance.

This suggests a possible encoding scheme in which geometric positions are represented through a single numerical parameter.

The practical value depends on the number of bits required to store the parameter and the precision needed to reconstruct the target.

### 7.2 Information compression

A possible application is the representation of two-dimensional data using a one-dimensional numerical quantity.

However, dimensionality alone does not determine information content.

A successful compression method must demonstrate that the encoded representation requires fewer bits than the original representation, including any necessary metadata and error-correction information.

This remains an open experimental question for the proposed construction.

### 7.3 Reversible computation

The construction may also be relevant to reversible computation.

The target-approximation problem asks whether a parameter can be found that reconstructs a desired coordinate pair.

The inverse problem asks whether that parameter can be recovered from the coordinates.

These are different operations, and uniqueness cannot be assumed.

A practical reversible implementation would require a carefully specified encoding convention and sufficient precision.

### 7.4 Higher-dimensional generalizations

The construction can be extended to additional oscillatory coordinates.

For example,

\[
F(t)=
(\cos t,\sin(\sqrt{2}t),\cos(\sqrt{3}t)).
\]

The corresponding flow can be studied on a three-dimensional torus.

More generally, rationally independent frequencies permit dense flows on higher-dimensional tori.

This provides a framework for investigating one-parameter representations of higher-dimensional regions.

## 8. Limitations

Several limitations should be acknowledged.

First, density guarantees that a suitable parameter exists but does not guarantee that it can be found quickly.

Second, a finite numerical representation of the parameter introduces rounding errors.

Third, the construction does not establish a unique parameter for every target point.

Fourth, density does not imply uniform coverage over a finite search interval.

Finally, the construction does not automatically provide information compression or a physical dimensional reduction.

These issues should be addressed through further theoretical and computational work.
